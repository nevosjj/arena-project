# arena-project
This datapack is a recreation of Hypixel's Arena Brawl, made by nevosjj.

## Technical Details

This datapack was designed to be used inside a pre-existing world, which will be provided within the release files.

It was not designed with compatibility for other datapacks in mind. However, support for compatibility may be considered in the future if requested.

## Game Modes

Matches can be played with a minimum of 2 players, up to an unlimited number of players in FFA mode.

Available game modes:
- 1v1
- 2v2
- FFA

FFA mode allows free-for-all matches with an effectively unlimited number of players.

## Gameplay Details

Just like in the original Arena Brawl, players can fight using 4 different abilities:
- Offensive
- Utility
- Support
- Ultimate

Each ability category comes with its own mechanics and gameplay depth to explore in-game.

Unlike the original Arena Brawl, matches can also feature:
- Round-based gameplay
- Life-based gameplay
- Competitive draft bans

Different playstyles for different players.
